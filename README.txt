SISTEM RADIO - CHAT OPERATIV

1. Instaleaza Python 3.
2. Deschide CMD in folderul programului.
3. Ruleaza:
   pip install -r requirements.txt
4. Porneste:
   python app.py
   sau dublu click pe run.bat
5. Intra in browser la:
   http://127.0.0.1:5000
